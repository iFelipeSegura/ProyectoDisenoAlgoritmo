INSTALACIÓN:

1. Instalar dependencias

    pip install -r requirements.txt

2. Ejecutar

    streamlit run app.py

API KEY

La API KEY de OpenRouteService se edita directamente en:

    app.py

Buscar:

    API_KEY = "..."
